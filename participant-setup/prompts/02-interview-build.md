# Build through an interview

Run `pixi run interview`, then paste:

```text
/skill:grill-me I want a tiny interactive terminal coding agent using read, write, edit and bash. Use the workshop LLM connection and show tool calls and results.

Ask me one question at a time, with your recommendation. Once we agree, build it in attempt-02 and add pixi run agent-02. Support --dir with paths relative to the repository root. Keep the conversation open for follow-ups. Leave attempt-01 alone. Show me it works.
```
