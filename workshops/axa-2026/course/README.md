**Recommended:** path 5. It matches the published promise and leaves participants with a reusable loop. Paths 2–4 give you alternatives if the audience is more advanced or the time shifts.

Open the selected board before the session. Its first frame is identical in every path. Move to the second frame for the build and the third for evidence and discussion. Keep the web workbench open in another tab.

Thirty people: use 15 pairs. Switch driver and reviewer halfway through the build. Ask pairs to predict results before clicking Run. At each checkpoint, collect a show of hands: running / stuck / finished. Use one prepared failure to start discussion, then ask for one audience failure.

**Leave with:** a working small artifact, a test or review criterion, one observed failure, and one reusable instruction. Finishing an advanced extension is not required.
