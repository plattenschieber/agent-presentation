# The One and Only Agent

20 Folien, je etwa 20 Sekunden: 6 Minuten 40 Sekunden. Deutsche Moderation, englischer Titel. Bei 5 Minuten gezielt kürzen; bei 10 Minuten maximal drei Minuten Diskussion anhängen. Die Sprecheransicht enthält den vollständigen Sprechtext.

## Start

```sh
npm ci
npm run dev:round9
```

Mit Pfeiltasten weiter. Die Zeitangaben sind Sprechtempo-Hilfen, kein automatischer Folienwechsel. Auf dem Titel starten und einen separaten 6:40-Timer benutzen. Ein technisches Live-Demo ist nicht erforderlich.
